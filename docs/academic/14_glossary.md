# GLOSSARY

The following technical terms, abbreviations, and acronyms are used throughout this report:

- **ACID**: Atomicity, Consistency, Isolation, Durability — A set of properties guaranteeing that database transactions are processed reliably.
- **API**: Application Programming Interface — A set of protocols and tools for building software applications and integrating external services.
- **Bcrypt**: A password-hashing mathematical function based on the Blowfish cipher incorporating a salt to protect against rainbow-table attacks.
- **CDP**: Chrome DevTools Protocol — A protocol that allows automated tools to instrument, inspect, and profile Chromium-based browsers (Chrome/Edge).
- **Cold-Start Problem**: An issue in recommender systems where the system cannot draw inferences for users or items about which it has gathered insufficient information.
- **CRUD**: Create, Read, Update, Delete — The four basic functions of persistent storage in database-driven applications.
- **CSRF**: Cross-Site Request Forgery — An attack that forces an authenticated end-user to execute unwanted actions on a web application in which they are currently authenticated.
- **DFD**: Data Flow Diagram — A graphical representation of the "flow" of data through an information system.
- **DTO**: Data Transfer Object — An object that carries data between processes or application layers to reduce the number of method calls.
- **ERD**: Entity-Relationship Diagram — A visual model depicting the entities, attributes, and relationships within a relational database.
- **IDOR**: Insecure Direct Object Reference — A security vulnerability where an application exposes a reference to an internal object without access control checks.
- **Jaccard Similarity**: A statistic used for gauging the similarity and diversity of sample sets, defined as the size of the intersection divided by the size of the union.
- **MMR**: Maximal Marginal Relevance — A diversification ranking technique that balances the relevance of items to a query/profile with the novelty/diversity of items relative to previously selected candidates.
- **MVC**: Model-View-Controller — A software architectural pattern dividing an application into three interconnected components: data (Model), presentation (View), and logic (Controller).
- **PDO**: PHP Data Objects — A lightweight, consistent data-access abstraction layer for PHP providing secure prepared statement interfaces.
- **PSR**: PHP Standard Recommendation — Technical specifications published by the PHP Framework Interop Group (PHP-FIG) for standardizing coding style (PSR-1, PSR-12) and autoloading (PSR-4).
- **SQL**: Structured Query Language — A domain-specific programming language designed for managing data held in relational database management systems.
- **SQLite**: A C-language library that implements a small, fast, self-contained, high-reliability, full-featured, SQL database engine.
- **TTL**: Time-To-Live — A mechanism that limits the lifespan or lifetime of cached data in a computer system.
- **UML**: Unified Modeling Language — A standardized modeling language enabling developers to specify, visualize, construct, and document software artifacts.
- **WAL**: Write-Ahead Logging — A SQLite transaction logging protocol that provides concurrent reading and writing by appending updates to a separate write-ahead log.
- **XSS**: Cross-Site Scripting — A security vulnerability enabling attackers to inject malicious client-side scripts into web pages viewed by other users.
